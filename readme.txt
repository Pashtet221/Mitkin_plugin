MITKIN — Готовые образы
Версия 1.0.0

Установка

1. В WordPress откройте «Плагины → Добавить плагин → Загрузить плагин».
   Загрузите ZIP и активируйте. Нужен активный WooCommerce.
2. Откройте «WooCommerce → Готовые образы» и создайте образ.
3. Задайте название, фото карточки и при необходимости отдельное фото для окна.
   В поле «Товары из каталога» найдите товары по названию. Добавьте минимум два.
4. Чтобы показать размеры только определённого цвета, найдите ID товара
   и ID нужных вариаций в «Товары → Редактировать → Вариации».
   Впишите их в поле «Разрешённые вариации по товарам», например 123: 456, 457.
   Для вариаций задайте конкретные значения всех атрибутов. Вариации
   с настройкой «Любой размер» или «Любой цвет» в образе не показываются.
5. Опубликуйте образ. На странице добавьте шорткод [mitkin_looks].
   В Elementor используйте виджет «Шорткод».
   Можно вывести конкретные образы [mitkin_looks ids="25,29"].
   Чтобы вывести только первые две карточки, используйте [mitkin_looks limit="2"].
   Параметр limit принимает целое число больше нуля и работает вместе с ids.
   Чтобы скрыть заголовок, добавьте heading="no".
   По умолчанию сортировка использует поле «Порядок» образа.
6. Для визуальных групп в корзине используйте классическую корзину WooCommerce
   [woocommerce_cart]. Если в корзине используется блок WooCommerce, позиции
   сохраняют расчёт скидки и данные образа, оформление групп рассчитано
   на классический шаблон корзины. Для показа групп подключите шорткод
   на странице, назначенной корзиной WooCommerce.

Покупка

Все доступные вещи по умолчанию отмечены. Для вариативного товара покупатель
подтверждает размер. Если у вариаций разные цены, карточка показывает минимальную
сумму, а окно пересчитывает её по выбранным товарам и размерам.

Скидка 7% применяется к текущей цене каждой позиции полного образа с округлением
до настроенной точности валюты. При снятии галочки или удалении позиции из
корзины скидка этого образа снимается. При повторном добавлении образ занимает
свою группу. Чтобы купить два одинаковых комплекта, добавьте образ дважды.

В корзине и заказе сохраняются обычные товарные позиции WooCommerce с реальными
ID, вариациями и ценами. Складской учёт, доставка и позиции чека обрабатываются
установленными интеграциями WooCommerce. Название образа записывается в метаданные
позиции заказа. Оплата и доставка требуют настройки и проверки на вашем стенде.
